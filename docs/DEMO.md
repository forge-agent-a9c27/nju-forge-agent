# 两分钟演示方案

目标是展示一次真实“发现问题—修改—验证—总结”，不要只展示聊天或预先写好的成功答案。

## 录制前

1. 把公开仓库地址填入 `README.txt`，确认工作区无任何真实凭据和 `.forge` 目录。
2. 在一个独立的小型示例项目中准备一个失败测试和对应实现；先在终端运行测试，让失败可见。
3. 在录屏区域外设置模型相关环境变量。关闭会显示环境变量、历史命令或通知的窗口。
4. 终端字号调大，执行 `python agent.py -w <示例项目>`。使用默认 `ask` 模式。

## 时间轴

- 0:00–0:12：一句话定位——“Forge 是从零实现、可回滚且带安全审批的本地 coding agent”。展示仓库结构。
- 0:12–0:25：输入真实任务，例如“阅读失败测试，定位并修复库存预留的原子性问题，运行测试，说明修改”。
- 0:25–1:20：保留 agent 的 `list/read/search`、`update_plan`、`edit` 和测试命令过程。等待段可加速，但让关键 tool result 可读。
- 1:20–1:38：展示测试由失败变为通过，以及 agent 最终总结；打开 diff，指出改动并非预置输出。
- 1:38–1:52：快速演示安全点：让它尝试读取工作区外路径，展示拒绝；或展示编辑返回的 undo 事务号。
- 1:52–2:00：展示 `python -m unittest discover -s tests -q` 的项目自测结果，收尾。

## 讲解要点

只讲三层：模型产生结构化决策；自研循环把结果写回上下文并决定继续/停止；工具层负责真实执行与确定性安全边界。强调命令分类不是沙箱、确定性摘要的取舍、SHA-256 乐观锁如何避免覆盖用户并行修改。视频必须小于 200 MB、mp4 格式；剪辑和加速可以使用，但不展示任何凭据。
